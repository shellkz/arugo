# 情境

程式設計期末專案，回合制 Roguelike，玩家行動才推進時間。

## 遊戲規則

**玩家**
- 四方向移動
- 移動後，若敵人在攻擊範圍內自動攻擊

**敵人**
- 玩家回合結算後，存活的敵人才行動
- 移動後，若玩家在攻擊範圍內自動攻擊

**地圖**
- TileMap
- 傳送門 → 前往下一層
- 隨機分布敵人

## 核心樂趣
- **心理博弈**：先等待對方衝過來，再往前，避免自己跑進對方刀口
- **資源分配**：先殺小怪，就能接續行動；若兩隻湊在一起，甚至可以打到大怪兩次

## Tech Stack
- SFML 3.0
- C++17

# 運作概念

```cpp
//Game-Scope
int main()
{

    // Window Init
    sf::RenderWindow window(
        sf::VideoMode({800u, 600u}),
        "Arugo");
    window.setFramerateLimit(24);

    // Resources
    // ResourceManager::get().loadSomthing()
    ResourceManager::get().loadFont("default", "assets/fonts/NotoSerifTC-Medium.ttf")
    ResourceManager::get().loadTexture("tiles/top",         "assets/tiles/top.png");

    // Custom component Init
    GameWorld world;

    GameOverUI gameoverUI(sf::Vector2f(window.getSize()));
    TurnBanner turnBanner;
    FlashMessage flashMessage(sf::Vector2f(window.getSize()));

    // Game Loop
    while (window.isOpen())
    {
        // Input event
        while (const std::optional event = window.pollEvent())
        {

            // UI consume event first
            bool consumed = UI.handleEvent(*event, window);
            if (consumed)
                continue;
            // Remaining goes to GameWolrd
            world.input(*event);
        }

        // Loop Callback 'update()' before render each frame
        float deltaTime = deltaClock.restart().asSeconds();
        world.update(deltaTime);

        // UI update later to reflect GameWorldChange
        UI.getInfoFrom(world);
        UI.update(deltaTime);      
       

        // Rendering
        window.clear();
        window.draw(world);
        window.draw(UI);
        window.display();
    }
}
```

# 想法

## 簡單機制

| 機制 | 說明 |
|------|------|
| 擊暈 | 跳過該敵人行動 |
| 先手權 | 第一擊傷害加倍 |
| 擊殺過載 | 打死怪可回血，甚至溢出到上限的 120% |
| 移動兩次 | 移動時直接跳過敵人回合一次（透過改 TurnState）|

## 牽涉架構更改的機制

- 結束回合才判定傷害
- 玩家進入範圍 → 敵人「準備攻擊」，下一回合才打

## 可能的 UX 問題

1. **敵人同時行動很混亂**
   - 敵人一個一個 present
   - 移動 transition

2. **無法連續輸入（Input Ghosting）**
   - 視覺提示回合（顯示 PlayerTurn / EnemyTurn）
   - 玩家行動中再次輸入，跳過當前 present 並執行新行動
     - Phase 1：簡單跳過 present
     - Phase 2：input buffer 紀錄跳過時的輸入，可行動後再執行

## 重構目標
- BattlePhase 抽象成 State，帶 lifecycle callback
- 遊戲包成 class，main() 去跑
- Batch drawing（TileMap）
- Camera

## UI 候選
- 狀態提示（暈眩）
- 戰鬥 LOG

## 內容擴充
- 武器：槍、弓 → 撿拾即觸發，直接給狀態
- 物品：寶箱、藥水 → 撿拾即觸發，直接給狀態
- 回合 Buff：中毒

## 行有餘力
- Audio
- 傷害數字浮字 / 系統 log
- 迷宮生成

## Fancy Shit
- 複雜 UI → 投入也不見得好看
- Sprite animation → 全新大系統，時間不夠
- 行動速度 → 架構大改，時間不夠
- 背景：浮島、傳送門能量天梯、水沒都市
