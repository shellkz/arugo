# 編譯

## 環境需求
- CMake 3.16+
- SFML 3.1.0 安裝於 `C:/SFML-3.1.0`
- MinGW-w64（GCC，位於 `C:/mingw64`）
> 要自己編譯很麻煩！要安裝dependency像是SFML和MinGW，因為我的cmake file沒有自動從網路抓。
> 只是想看運行狀態，直接跑`dist/Arugo.exe`。


## 步驟

### Release
```powershell
# 1. Configure(產生cmake files，輸出到`build/release`)
cmake -B build/release -DCMAKE_BUILD_TYPE=Release -G "MinGW Makefiles"

# 2. 編譯(根據cmake files編譯，輸出到`build/release`)
cmake --build build/release

# 3. 打包(過濾`build/release`必要檔案，輸出到`dist/`，即可壓縮發布)
cmake --install build/release --prefix dist
```

### Debug
```powershell
# 1. Configure(產生cmake files)
cmake -B build/debug -DCMAKE_BUILD_TYPE=Debug -G "MinGW Makefiles"
# 2. 編譯
cmake --build build/debug
```

> **注意**：重新 configure 前，需先刪除再重建：
> ```powershell
> Remove-Item -Recurse -Force build\release
> Remove-Item -Recurse -Force build\debug
> ```

# 發布
所有發布需要的內容都在`dist/`，內容包含：
- `Arugo.exe`（SFML 與 C++ runtime 已靜態連結，不需要任何 DLL）
- `assets/`

將整個 `dist/` 壓縮後即可發布，對方電腦不需要額外安裝任何軟體。

## 注意事項

- 務必使用 **Release** 模式，Debug 模式的 exe 無法在其他電腦執行。
- 不要直接打包 `build/`，裡面包含 CMake 暫存檔。
- 編譯器必須用 **MinGW**，SFML 的 lib 是 MinGW 格式（`.a`），與 MSVC 不相容。
